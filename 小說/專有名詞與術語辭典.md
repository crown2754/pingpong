# 《乒乓》專有名詞與桌球術語辭典

為了讓不熟悉桌球的讀者也能順暢閱讀，以下整理了小說中出現的各式桌球專有名詞、器材、戰術以及致敬的現實人物原型。

## 一、 桌球器材與裝備 (Equipment)

* **底板 (Blade)**：桌球拍的木板本體，不含膠皮。分為純木底板與加入碳纖維（加料）的底板。
* **膠皮 (Rubber)**：貼在底板上的橡膠層，直接影響擊球的旋轉與速度。
* **橫拍 (Shakehand)**：像「握手」一樣的握拍方式，是目前世界桌球最主流的打法，正反手轉換最為靈活。
* **直板 / 中直 (Chinese Penhold)**：像「握筆」一樣的握拍方式，拍柄較短。「中直」特指中國式直板，除了正手攻擊外，背面也可貼膠皮進行「直拍橫打」。
* **日直 (Japanese Penhold)**：日本式直板，拍面多為方形或略圓，背面通常有一塊軟木突出，多為單面貼膠皮。正手攻擊力極其霸道，但反手防守相對弱勢（書中為家偉的武器）。
* **狂暴三 (Kuangbao 3)**：小說中的虛構膠皮（原型為著名的中國製「狂飈三」）。屬於「黏性膠皮」，需要使用者有較好的發力與摩擦基礎，能製造極強的旋轉與下沉球質。
* **X05**：小說中的虛構膠皮（原型為蝴蝶牌 Tenergy 05）。屬於頂級「澀性膠皮」，彈性極佳，極度適合快速反擊與借力打力。
* **矮豆 極光3 (Aido Aurora 3)**：主角陳森夫的第一把新手進階底板，容錯率高。
* **多米克 紅張 / 黃張 (Domick Red Zhang / Yellow Zhang)**：小說中的高階底板型號（原型為蝴蝶牌的張繼科 ALC/ZLC 簽名系列）。「紅張」吃球深、進攻極兇但容錯率低；「黃張」則偏向穩定與防守。
* **Teebar 免綁帶鞋**：專用桌球鞋品牌（原型為 Tibhar），止滑力強，對經常需要瞬間啟動與急停的桌球步法（如陳森夫的快速反擊）至關重要。

## 二、 技術與戰術術語 (Techniques & Tactics)

* **發接發 (Serve and Receive)**：桌球比賽前三板的核心。發球與接發球的質量與旋轉判斷，往往直接決定該回合的生死。
* **S-1 戰術**：主角陳森夫在軟體工程思維下自創的戰術代號（Short-1）。核心為「發短球牽制 → 穩定擋回 → 第三板壓迫大角」。
* **第三板 (Third-Ball Attack)**：發球方在對手接發球（第二板）後，打出的第三板球。這是桌球中最關鍵的搶攻時機。
* **擺短 / 搓長 (Drop shot / Long push)**：處理下旋球的技巧。「擺短」是輕觸球使其剛好越網落下，不讓對手輕易起板攻擊；「搓長」則是加力將球快速劈向底線，逼迫對手退台。
* **快帶 / 借力反擊 (Fast block / Counter)**：面對對手的強攻，不主動發大力量退台對拉，而是借用對方來球的速度與旋轉，在近台提早調整拍面角度，將球快速反彈回去，特點是節奏極快。
* **擰拉 / 反手擰 (Banana flick)**：現代桌球極具攻擊性的接發球技術。手腕極度內收，在台內直接用反手強力摩擦下旋短球，帶有強烈側上旋，是變被動為主動的殺招。
* **削球 (Chopping)**：一種以「防守反擊」為主的打法。選手站位離檯較遠，透過由上往下摩擦來球，製造強烈的「下旋球」，以耐心等待對手心急失誤（如書中的蔡文德）。
* **長膠 / 顆粒 (Long pips)**：削球手或怪球手常使用的膠皮。特性是會「反轉旋轉」（對手打上旋，回過去會變下旋），球路飄忽不定且會下沉，極難借力。

## 三、 賽制與訓練系統 (Systems)

* **館內分 / 聯盟分 (Club Rating / League Rating)**：業餘桌球界的積分系統。贏球加分、輸球扣分。「館內分」僅限同一球館的熟面孔，容易遇到分數飽和；「聯盟分」則是跨場館、跨區域的正式積分，更具鑑別度。
* **賽練**：結合比賽計分與特定戰術練習的對戰模式。比單純練球更貼近實戰壓力。
* **多球 (Multi-ball)**：教練或陪練員在桌邊連續、快速餵出大量桌球，讓選手在不間斷的節奏中形成肌肉記憶的訓練法。

## 四、 現實原型人物對照 (Character Homages)

* **馬承龍 (原型：馬龍)**：以精準的算球、無死角的全面控制與超強正手著稱，被譽為「六邊形戰士」。
* **樊震東 (原型：樊振東)**：以驚人的爆發力、暴力的反手擰拉與極高質量的中遠台反拉聞名。
* **張智和 (原型：張本智和)**：日本年輕新星，以極快的近台節奏與每贏一分都會瘋狂吼叫的激情著稱。
* **許昕舟 (原型：許昕)**：少數的頂尖左手中直選手，以極大的跑動範圍、正手爆衝與驚人的手感被稱為「人民藝術家」。
* **林均儒 (原型：林昀儒)**：台灣天才左手選手，以冷靜的表情與反手無解的「招牌擰拉」技術聞名世界。
* **莊志淵 / 莊武鴛 (原型：莊智淵 / 莊智雄)**：台灣桌球界的傳奇老將與其親兄（教練）。小說中以此為致敬，設定為主角成長的場館與指導者。

## 五、 軟體工程師專屬譬喻 (Software Engineering Metaphors)

由於主角陳森夫是一名 36 歲的資深軟體工程師，他的內心獨白與視角中經常會使用程式開發的術語來理解桌球。以下是書中常出現的工程術語對照：

* **Commit (提交)**：在版本控制系統（如 Git）中，代表確認並儲存修改。書中用來比喻「終於下定決心踏出第一步，按下確認鍵」的實感。
* **API (應用程式介面)**：軟體之間溝通的橋樑。書中用來比喻「對手的球路與打球習慣」，解讀對手就像在閱讀一份未知的 API 文件；而選錯跟老婆溝通的方式，就像「傳錯了 API 參數」。
* **Deploy / 上線**：將寫好的程式碼推送到正式環境讓使用者使用，通常伴隨著高度壓力。書中用來比喻「正式比賽前」那種胃部緊繃的緊張感。
* **Middleware (中介軟體)**：在不同系統之間負責橋接、過濾或處理錯誤的軟體層。書中用來比喻「黃張」底板的高容錯率，像是一層幫忙把發力失誤給悄悄抹平的軟體。
* **單元測試 (Unit Test)**：針對程式碼中最小單位進行的正確性測試。書中用來比喻「在熟悉的球館裡反覆練習到不會出錯的肌肉記憶」。
* **Try-Catch**：程式語言中用來「捕捉並處理錯誤」的語法。書中用來形容家偉試圖掩蓋緊張情緒，「表面上把錯誤包起來，假裝沒事」。
* **Debug (除錯)**：尋找並修正程式錯誤的過程。書中用來形容森夫以 0.25 倍速慢動作研究球星腳步，試圖找出自己動作的問題。
* **Spec (規格書)**：軟體開發前的詳細需求與標準文件。書中用來形容莊哥念分數時「像念規格書一樣毫無起伏」，或是將頂尖選手的動作當作「遙不可及的 Spec 先存進腦海」。
* **Latency (網路延遲)**：資料傳輸的延遲時間。書中用來形容對手打球極快（「像延遲被拔掉」），或是自己穿錯鞋子打滑（「像網路延遲突然飆高，動作做完了畫面還沒跟上」）。
* **函式 (Function) 與 回傳值 (Return Value)**：程式中的功能區塊。書中用來幽默地形容老婆娜娜的笑話：「像某段被反覆呼叫的函式，每次執行，回傳值都一樣」。
