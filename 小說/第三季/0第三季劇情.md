# 第三季劇情大綱：內置的哲學

## 核心主軸
1. **裝備降級與心態重構**：第二季末，森夫因為無法駕馭「紅張」（外置碳纖維，要求極高的自身發力與基本功）而遇到瓶頸（卡住的晚上）。第三季開頭，他決定放下對「頂級裝備=頂級技術」的迷思，改換日系老牌**米他庫的「藍天」**內置底板。
2. **「讓球拍教你打球」**：藍天底板搭配 **GG1 (正手) / CC1 (反手)** 蛋糕海綿膠皮。這種配置的容錯率極高，吃球深。森夫不再需要用蠻力或極度精確的角度去硬吃對手，而是學會感受球在拍面上的「停頓感」，體會日本人對手感的細緻追求。
3. **戰術進化**：從「提前反擊」的極限壓迫，轉變為依靠超高「上台率」與旋轉變化的穩定輸出。

## 關鍵裝備設定
- **底板：藍天**
  - **結構**：內置碳纖維（Inner Carbon）。木層在外面，碳纖維貼近大芯。輕發力時像純木般柔和，發大力時才有碳纖維的底勁。
  - **意義**：相較於外置的紅張，藍天更包容。它要求使用者「把動作做完整」，只要動作對了，球拍就會幫你把球送上台。
- **膠皮：GG1 / CC1**
  - **特色**：大氣孔的「蛋糕海綿」，抓球感極強，起下旋非常容易。正手 GG1 強調旋轉與力量，反手 CC1 偏向穩定與防守控制。
