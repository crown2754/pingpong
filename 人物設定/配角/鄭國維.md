# 鄭國維

## 基本資料

| 項目 | 內容 |
|------|------|
| 年齡 | 四十歲上下 |
| 身分 | 雙和積分站聯盟選手；森夫低潮期第一個對手 |
| 積分帶 | 約 **1415**（2028/2） |
| 持拍 | 中直；發球小、薄、轉 |

## 一句話

不靠大板、也不送分的中直老手，專門把球放回你最不舒服的地方，逼你自己先不耐煩。

## 與森夫的比賽

- **初登場**：`第十七章｜慢半拍`
- **結果**：森夫 **1:3 負**
- **作用**：讓森夫的「每一板都想打對」在實戰裡爆開——不是輸給怪招，是輸給半拍。

## 打法特徵

- 發球小而轉，接發不冒進，第三板也不急著搶。
- 沒有明顯殺板，靠落點（中路、反手、正手大角）與低失誤累積壓力。
- 面對對手遲疑時會立刻加壓，但不貪漂亮。

## 劇情備註

- 賽後只點頭、擦汗，像做完一件正常工作——這種「正常」比輸球本身更冷。
- 黃俊宇去年也輸過他：「這種最煩。你越想打漂亮，他越不讓你漂亮。」
