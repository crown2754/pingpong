# 林建邦

## 基本資料

| 項目 | 內容 |
|------|------|
| 年齡 | 五十歲 |
| 身分 | 莊武鴛館內資深學員；森夫第三季館內賽對手 |
| 球齡 | 從小打球，動作受過正式訓練 |
| 打法 | 橫拍，教科書派；動作標準、腳步完整 |

## 一句話

每一球都到位、每一板都漂亮的老派選手；他證明「把每一分力氣都花在到位」會撞到什麼牆。

## 與森夫的比賽

- **初登場**：`第二十章｜手腳分離`
- **結果**：森夫 **3:2 苦勝**（9:11 / 11:7 / 11:9 / 7:11 / 11:9）
- **作用**：作為「手腳分離」的對照組——證明無限追求「每球到位」的極限在哪裡。

## 打法特徵

- 發球不高、站位正、接發不冒高、第三板不搶；**靠不失誤累積壓力**。
- 每一球都完整跑到位、完整做完動作，一分也不省。
- 弱點：**還原慢、續航有限**——每一球都跑，所以每一球之間都慢半拍回到中間。

## 角色意義

- 他三十五歲時被教練稱讚「每一球都到位」，當時很得意；如今五十歲，只剩到位。
- 賽後對森夫說：「我三十五歲的時候，教練說我每一球都到位。我當時很得意。……現在我只剩下到位了。」
- 這句話是森夫「八二法則」的觸發點之一：**到位是最基本的事，不是最終的答案。**

## 劇情備註

- 館內分賽事，不影響森夫聯盟分（維持 1341）。
- 適合未來回收：森夫若在更高層級再遇「動作完美型」對手，可作為對照。
