# 潘柏成

## 基本資料

| 項目 | 內容 |
|------|------|
| 年齡 | 三十出頭 |
| 身分 | 雙和積分站聯盟選手；森夫低潮期第二個對手 |
| 積分帶 | 約 **1392**（2028/2） |
| 持拍 | 右手橫拍 |

## 一句話

前衝快、接發後第一下很果斷的中階選手；他什麼都不知道，只是照自己的節奏打，就把對面那個想太多的人拖垮了。

## 與森夫的比賽

- **初登場**：`第十七章｜慢半拍`
- **結果**：森夫 **1:3 負**
- **作用**：與鄭國維連成雙敗，把森夫推進《卡住的晚上》的低潮谷底。

## 打法特徵

- 發球不難看，重點在接發後的第一下——乾淨、直接、不猶豫。
- 不讀對手的心理，只打自己的球。
- 屬於「不特別強，但完全沒有多餘動作」的實用型對手。

## 劇情備註

- 森夫賽中最糟的念頭出現在這場：*是不是紅張根本不適合我。*
- 他明知問題不在拍子，卻發現低潮時連最信的東西都想拖出來怪一下。
